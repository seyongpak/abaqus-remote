# Instructions for AI coding agents

This repo provides the `abq` command, which runs Abaqus Python scripts inside the user's open
Abaqus/CAE session (Windows) from WSL.

When the user asks for anything in Abaqus, follow `skill/abq/SKILL.md`.
Quick reference: `abq ping` checks the link; `abq script.py [timeout_s]` runs a script and prints
`OK`/`ERROR` plus its output.
